# Code of Conduct

Pantry follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Harassment, insults and bad-faith participation are not welcome, in issues, pull requests or
anywhere else the project lives.

The maintainers may warn, restrict or ban anyone who makes the project worse for others.

To report a conduct problem, contact a maintainer through GitHub, or privately if you prefer.
